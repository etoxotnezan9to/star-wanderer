# Протоколы проверки настройки площадки

Здесь лежат протоколы проверки настройки площадки этого репозитория
попыткой (AGENTS.md, 6.6): их печатает средство комплекта
`kit/.branch-kit/tools/owner_check_settings.py` после попыток ключами
ролей — отправки, принудительной отправки, удаления, слияния, заметки.

| Файл | Что в нём |
|---|---|
| `2026-10-10-1.yaml` | первый запуск, до защиты веток задач: защищена только `main`; две попытки из восьми прошли не как ожидалось (принудительная отправка в пробную ветку и её удаление), ветка возвращена из копии |
| `2026-10-10-2.yaml` | второй запуск, после постановки защиты веток задач (пять правил веток задач по префиксам из настройки): всё как ожидалось, копия не понадобилась |

Имя файла — `<дата>-<номер>.yaml`: дата запуска в виде ГГГГ-ММ-ДД и
порядковый номер запуска за этот день, с 1.

Протоколы вносят обычным запросом: решений они не несут, нормы не меняют
(AGENTS.md, 2.1). Записи в протоколах не правят: это дословные ответы
площадки на момент запуска; новая проверка — новый файл.
