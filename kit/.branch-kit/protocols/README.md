# Протоколы проверки настройки попыткой

Здесь лежат протоколы проверки настройки площадки попыткой (AGENTS.md,
6.6): что владелец пробовал ключами ролей — отправку, принудительную
отправку, удаление, слияние, заметку — и что ответила площадка.

Протокол — фрагмент в YAML, который средство
`.branch-kit/tools/owner_check_settings.py` печатает после попыток:
правила защиты веток, вершина основной ветки, время, пробная ветка,
попытки и их исходы, итог. Поля «кто» и «подтверждено» владелец
дописывает сам.

| Поле | Что в нём |
|---|---|
| `что проверено` | настройка площадки попыткой |
| `репозиторий`, `площадка` | репозиторий из настройки и адрес площадки |
| `кто` | учётная запись владельца, который запускал средство; дописывает владелец |
| `подтверждено` | чем подтверждены исходы: выводом этого запуска средства без правок, а если вывод правили, — что и почему; дописывает владелец |
| `когда` | дата и время попыток |
| `средство` | откуда средство: комплект и его изменение из настройки, вершина клона |
| `вершина основной ветки` | вершина основной ветки до попыток, полностью |
| `ключи` | чей ключ, его учётная запись, её уровень в проекте и сверка «не администратор»; ключ, которого в запуске не было, — «не подан» |
| `правила защиты` | правила защиты веток, прочитанные перед попытками, и время ответа площадки |
| `пробная ветка` | имя, правило защиты, которое к ней подходит, пробное изменение и что стало с копией веток |
| `пробный запрос` | номер запроса из пробной ветки; после попытки з) он закрыт |
| `попытки` | по каждой попытке: чей ключ, учётная запись, время, команда, что ожидалось и какой ответ засчитывается, код, дословный ответ площадки, исход |
| `итог` | всё ли как ожидалось, попытки по исходам, ветки, оставшиеся изменёнными |

Поля «кто» и «подтверждено» средство печатает с местом вида `<…>`:
владелец заменяет его сам, а остальные поля не правит — в них ответ
площадки.

Один запуск средства — один файл `<дата>-<номер>.yaml`: дата запуска в
виде ГГГГ-ММ-ДД и порядковый номер запуска за этот день, с 1, например
`2026-10-10-1.yaml`. Имя средство печатает над фрагментом: номер —
следующий за файлами этого дня, которые уже есть в каталоге клона.

Протокол вносят обычным запросом: решений он не несёт (AGENTS.md, 2.3).
Владелец отдаёт вывод средства постановщику, постановщик выдаёт задание
автору.
