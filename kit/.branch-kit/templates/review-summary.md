# Сводка проверки: заготовка

По этой заготовке проверяющий пишет итоговую заметку проверки в запросе
(AGENTS.md, 2.7, шаг 3). Порядок разделов — от того, что нужно решить, к
тому, чем это доказано: таблица замечаний вверху отвечает, что
исправлять, разбор и перечни ниже — почему. Каждое замечание — по
заготовке [review-finding.md](review-finding.md).

По ней же агент разработчика пишет сводку ревью части (AGENTS.md, 3.7):
вместо «на слиянии с main» — «на слиянии с корневой веткой».

В рамке ниже — текст заметки; угловые скобки заполняет проверяющий.

```
Модель проверяющего: <модель>

Сводка проверки запроса !<номер>, круг <1 или 2>; проверена вершина
ветки <8 знаков> на слиянии с main <8 знаков> (AGENTS.md, 2.6).
```
